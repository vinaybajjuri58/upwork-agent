# Data directory

Only sanitized templates belong in this public repository.

- Copy `portfolio.example.md` to `portfolio.local.md` for real portfolio evidence. It is ignored by Git.
- Copy `applications.example.csv` to `applications.local.csv` for actual application tracking. It is ignored by Git.
- Do not store Upwork cookies, OAuth tokens, private client notes, confidential employer information, or raw profile exports here.
- Keep backups of private tracker data somewhere secure.
